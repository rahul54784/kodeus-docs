Warren currently supports two ways to authenticate:

- Wallet authentication
- Email authentication with OTP verification

## Wallet authentication

You can access Warren using supported wallets.

### Current flow

1. Open Warren
2. Select wallet login
3. Approve the authentication request
4. Complete session verification
5. Continue onboarding

### What wallet authentication is used for

- Account access
- Session authorization
- Platform identity

## Email authentication

You can also access Warren using email verification.

### Current flow

1. Enter your email address
2. Receive an OTP verification code
3. Verify your session
4. Continue onboarding

Both authentication paths land you in the same personalized onboarding flow.
