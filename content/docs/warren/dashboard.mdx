After activation, you are redirected to the Warren dashboard.

## What the dashboard includes

- Portfolio metrics
- Market regime visibility
- Runtime strategy visibility
- Active strategy monitoring
- Performance tracking
- Strategy runtime state
- Conversational Warren access

## Current dashboard signals

![Leaderboard](/docs/images/warren/leaderboard.png)

- Bullish or bearish market regime
- Multi-timeframe analysis
- Win rate tracking
- Strategy runtime visibility
- Live or paper strategy status

The dashboard is where you keep ongoing visibility into every strategy Warren is running and every signal it has detected.
